# Discord 表情反應標記機器人

掃描 Discord 訊息上的指定反應（預設 ✅），自動 @mention 每個按過該反應的用戶，並支援附加自訂訊息。

---

## 功能

- 掃描指定訊息的反應（預設 ✅，可透過指令參數或環境變數自訂）
- 自動標記（@mention）按過該反應的用戶
- 支援附加自訂訊息，一併送出
- 自動過濾機器人的反應
- 防止意外觸發 @everyone / @here

---

## 所需權限

| 權限             | 說明             |
| ---------------- | ---------------- |
| 檢視頻道         | 存取目標頻道     |
| 讀取訊息歷史記錄 | 抓取訊息及其反應 |
| 傳送訊息         | 回覆結果         |
| 嵌入連結         | 顯示訊息跳轉連結 |

---

## 使用方式

| 指令                                               | 功能                          |
| -------------------------------------------------- | ----------------------------- |
| `/reactions message_id:<id>`                       | 標記該訊息中按該 emoji 的用戶 |
| `/reactions message_id:<id> custom_message:<文字>` | 標記後附加自訂訊息一併送出    |

### 輸出範例

```
@小明 @小美 @阿哲 @大衛 @小芳 @阿偉
活動開始囉！
```

---

## 環境變數

在專案根目錄建立 `.env`（可參考 [.env.example](.env.example)）：

| 變數            | 說明                                  |
| --------------- | ------------------------------------- |
| `DISCORD_TOKEN` | 機器人的 Discord Bot Token            |
| `DEFAULT_EMOJI` | 預設篩選的反應 emoji（可選，預設 ✅） |

---

## 使用 Docker 執行

```bash
docker compose up -d --build
```

查看日誌：

```bash
docker compose logs -f
```

停止機器人：

```bash
docker compose down
```
